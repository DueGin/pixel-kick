# PIXEL KICK · 2.5D 像素足球

本地双人 1v1 像素足球对战，每队另有一名 AI 门将。纯 HTML5 Canvas + 原生 JS，无依赖、无素材文件（音效由 WebAudio 实时合成）。

**运行：** 直接用浏览器打开 `index.html`。

| | P1 红队 | P2 蓝队 |
|---|---|---|
| 移动 | `W A S D` | 方向键 |
| 射门（按住蓄力）/ 铲球 | `F` | `K` 或 `.` |
| 挑射 / 起跳头球 | `G` | `L` 或 `/` |

空格/回车开始，`P`/`Esc` 暂停（暂停时 `Q` 回标题），`M` 静音，标题页 `←` `→` 选比赛时长。支持两个手柄。

手感参数在 `js/config.js` 的 `PHYS` 中调整。
